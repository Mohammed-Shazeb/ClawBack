## The one real bug found and fixed (mock, not app)

`npm run seed` (the new demo-data script) failed with:

```
email: INBOUND FAILED "The statement could not be read as structured data."
```

Root cause: **`scripts/mock-providers.mjs` `categoryFor()` fell back to `"OTHER"`,
which is not in `convex/validators.ts` `DEDUCTION_CATEGORIES`
(`ORDINARY_WEAR | TENANT_DAMAGE | FEE | UNKNOWN`).** The app validates every
provider response against its Zod schema before persisting, so one bad category
rejected the *whole* statement. The app was right; the mock was wrong.

Why it hid for so long: every record in the e2e `STANDARD_RECORDS` fixture
(`Painting`, `Carpet replacement`, `Broken cabinet`, `Administrative fee`)
happens to match a known pattern, so the fallback was never reached. The seed's
`Cleaning: $100` was the first line to fall through.

Fix: fallback is now `UNKNOWN` (the app's own "not enough information" value),
patterns mirror `EXTRACTION_SYSTEM_PROMPT` (fee / tenant damage / ordinary wear),
and `assertCategory()` throws loudly if the mock ever emits a value outside the
enum again.

Regression test: `scripts/verify-e2e.mjs` section 35 delivers a statement with an
unclassifiable charge (`Miscellaneous charge: $75`) to a fresh case and asserts
the email is PROCESSED and the category is `UNKNOWN`. **Proved meaningful** by
temporarily restoring `return "OTHER"` — exactly those 4 checks failed with the
real error, and the other 235 still passed. 234 → 239 e2e checks.

## Live verification harness (new)

`scripts/verify-live.ts` + `npm run verify:live`. Bundles and imports the **real**
prompts, JSON Schemas and validators from `convex/` — it does not restate them.
Covers OpenAI (extraction, assessment, letter, response analysis), Firecrawl
(search + `classifyAuthority`), and AgentMail (read-only auth probe).

**It never sends mail.** A real outbound send needs a real recipient address.
`convex/openai.ts`, `firecrawl.ts`, `errors.ts`, `agentmail.ts`, `extraction.ts`,
`assessment.ts`, `letter.ts`, `response.ts`, `questions.ts` are all importable
offline (only `zod` / `./validators` / `import type` from `_generated`).

## Environment gotchas hit again

- **Never start the mock with a shell `&`** — the process is killed when the Bash
  call returns. Use `run_in_background: true`. A 4m50s "e2e run" was invalid
  because the mock had died; the harness buffers all output until the end, so it
  looked like a hang.
- `curl -o /dev/null` returns exit 23 on this Git Bash, which short-circuits a
  `&&` chain. Do not chain after it.
- `npx convex dev` and the mocks must both be running for `verify:e2e`.
